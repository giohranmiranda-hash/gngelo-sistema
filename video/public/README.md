Coloque aqui as imagens/vídeos usados no projeto.

## Foto do produto

1. Copie a foto pra esta pasta, ex: `produto.jpg`
   (recomendado: vertical ou quadrada, pelo menos 1080px de largura).
2. Abra `../src/content.ts` e escreva o nome do arquivo em `productPhoto`:

   ```ts
   productPhoto: "produto.jpg",
   ```

3. Rode `npm run dev` pra ver no preview.

Enquanto `productPhoto` estiver vazio, a cena mostra um espaço reservado.
